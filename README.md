## ✨ About this project

This repository contains the source code for my personal developer portfolio: a visual home for my projects, technical interests, skills, and professional journey.

The site is designed around a polished, navy-and-ocean visual identity, with motion and detail used to make the experience engaging while keeping the content readable. It brings project showcases, project detail pages, technical skills, profile information, and résumé access into one responsive experience.

> **Explore the live site:** [saisrinivasportfolio.lovable.app](https://saisrinivasportfolio.lovable.app)

## 🚀 Run locally

### Prerequisites

- Node.js (a current LTS release is recommended)
- npm, or Bun if you prefer the repository's Bun tooling

### Setup

```bash
git clone https://github.com/Sai-Srinivas-P/SAI-SRINIVAS-PATIBANDLA-PORTFOLIO.git
cd SAI-SRINIVAS-PATIBANDLA-PORTFOLIO
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

### Available scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run build:dev` | Build using development mode |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
